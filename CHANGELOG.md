# Changelog

## 0.2.0 (unreleased)

Linux x86-64 Conda packages, native installed-consumer checks and platform-bound
artifact verification. PTX checks include sm_86; CUDA hardware acceptance is pending.

## 0.1.0

Initial release. Named-axis transforms, reductions, contractions and borrowed views.
Float32 GPU transforms, numeric reductions and binary contractions; Apple Metal
parity checks and NVIDIA PTX compilation. Float64 CPU support is unchanged.
